Как добавить инструмент в Даймона: GitHub-write

Где живёт код — два места

Место Описание
1 /root/daimon/bot.py на сервере Здесь код живёт и запускается. Это твой экземпляр.
2 github.com/sergeyr8manov/DAIM8N Резервная копия + история изменений.

Сервер: 178.236.255.254, заходишь по SSH.

Как работает любой инструмент — паттерн

В bot.py каждый инструмент — это две части:

Часть 1 — описание для ИИ (TOOLS_SPEC, ~строка 150)

Это JSON-схема. DeepSeek видит её и знает: «такой инструмент существует, вот что он принимает».

{"type": "function", "function": {"name": "имя_инструмента",
    "description": "Что делает — ИИ читает именно это",
    "parameters": {"type": "object", "properties": {
        "параметр": {"type": "string", "description": "Что это за параметр"}},
        "required": ["параметр"]}}},

Часть 2 — логика (exec_tool, ~строка 400)

Здесь Python-код: что реально происходит когда ИИ решил вызвать инструмент.

if name == "имя_инструмента":
    param = args.get("параметр")
    # ... делаем что-то ...
    return "результат строкой"

ИИ получает строку обратно и включает её в ответ.

Шаги: добавить github_write_file

Шаг 1 — Зайти на сервер

ssh root@178.236.255.254
# Спросит пароль — он у тебя есть

Шаг 2 — Добавить токен в .env

nano /root/daimon/.env

Добавь строку в конец (токен с правами на запись в нужный репо):

GITHUB_TOKEN=ghp_ТВОЙ_ТОКЕН_ЗДЕСЬ
GITHUB_REPO=sergeyr8manov/DAIM8N

Сохрани: Ctrl+O, Enter, Ctrl+X.

Где взять токен: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → New. Дай права Contents: Read & Write на нужный репозиторий.

Шаг 3 — Открыть bot.py

nano /root/daimon/bot.py

Шаг 4 — Найти конец TOOLS_SPEC (Ctrl+W в nano → ищи delete_event)

Прямо перед закрывающей ] добавь:

    {"type": "function", "function": {"name": "github_write_file",
        "description": "Сохранить текст как файл в GitHub-репозиторий. Для заметок, конспектов, итогов встреч.",
        "parameters": {"type": "object", "properties": {
            "path": {"type": "string", "description": "Путь файла, напр. 'notes/2026-06-23.md'"},
            "content": {"type": "string", "description": "Содержимое файла"},
            "message": {"type": "string", "description": "Краткое описание (необязательно)"}},
            "required": ["path", "content"]}}},

Шаг 5 — Найти конец exec_tool (Ctrl+W → ищи неизвестный инструмент)

Прямо перед строкой return f"неизвестный инструмент: {name}" добавь:

        if name == "github_write_file":
            import base64 as _b64
            path = (args.get("path") or "").strip()
            content = args.get("content", "")
            message = args.get("message") or f"update {path}"
            token = os.environ.get("GITHUB_TOKEN", "")
            repo = os.environ.get("GITHUB_REPO", "sergeyr8manov/DAIM8N")
            if not token:
                return "нет GITHUB_TOKEN в .env"
            if not path:
                return "не указан путь файла"
            b64 = _b64.b64encode(content.encode()).decode()
            url = f"https://api.github.com/repos/{repo}/contents/{path}"
            headers = {"Authorization": f"Bearer {token}",
                       "Accept": "application/vnd.github+json",
                       "Content-Type": "application/json"}
            req = urllib.request.Request(url, headers=headers)
            try:
                with urllib.request.urlopen(req, timeout=10) as r:
                    sha = json.loads(r.read()).get("sha", "")
            except Exception:
                sha = ""
            payload = {"message": message, "content": b64}
            if sha:
                payload["sha"] = sha
            req2 = urllib.request.Request(url, data=json.dumps(payload).encode(),
                                          headers=headers, method="PUT")
            try:
                with urllib.request.urlopen(req2, timeout=15) as r:
                    json.loads(r.read())
                return f"файл '{path}' сохранён в {repo}"
            except Exception as e:
                return f"ошибка: {e}"

Сохрани: Ctrl+O, Enter, Ctrl+X.

Шаг 6 — Проверить синтаксис и перезапустить

python3 -m py_compile /root/daimon/bot.py && echo "синтаксис OK"
systemctl restart daimon
sleep 2
systemctl is-active daimon

Должно быть active.

Шаг 7 — Проверить что работает

Напиши Даймону:

«Сохрани в GitHub файл notes/test.md с текстом “привет из Даймона”»

Даймон должен вызвать инструмент и ответить: файл 'notes/test.md' сохранён.

Потом проверь в GitHub: github.com/sergeyr8manov/DAIM8N/blob/main/notes/test.md

Если что-то пошло не так

Синтаксическая ошибка — py_compile скажет на какой строке. Смотри отступы (Python чувствителен).

нет GITHUB_TOKEN в .env — токен не сохранился. Проверь: cat /root/daimon/.env | grep GITHUB.

400 Bad Request от GitHub — токен без прав на этот репо. Пересоздай с Contents: Read & Write.

active не появилось — смотри логи: journalctl -u daimon -n 20.
