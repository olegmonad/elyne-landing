Свой ChatGPT на DeepSeek — пошаговый гайд

Этот гайд для двух людей: Алексея и Димы. У каждого будет свой сервер и свой ИИ-ассистент. Дима платит за оба сервера (нужна иностранная карта — она у него есть).

Что в итоге получите: личный веб-интерфейс, похожий на ChatGPT. Заходишь через браузер по ссылке, общаешься с ИИ. История сохраняется, можно создать несколько «ассистентов» с разными задачами (контент, маркетинг, личный помощник). Работает на мозгах DeepSeek — это китайский ИИ, очень близкий по качеству к ChatGPT, но значительно дешевле.

ШАГ 1. Заказать VPS на nktele.com

Это нужно сделать дважды — по одному серверу на человека. Дима делает оба заказа со своей карты.

  1. Открыть в браузере: https://nktele.com
  2. Нажать «VPS/VDS» в меню (или перейти по https://nktele.com/vps-vds/)
  3. Выбрать тариф $8.99/мес (4 vCores, 4 GB RAM, 60 GB Disk)
  4. В настройках заказа выбрать: - Локация: Frankfurt или Amsterdam (ближе к России/СНГ, скорость будет лучше) - ОС: Ubuntu 24.04 LTS
  5. Пройти оплату картой
  6. На почту придёт письмо с тремя вещами: IP-адрес сервера, логин (обычно root), пароль

Сохрани это письмо — оно понадобится на следующем шаге.

Повторить процедуру для второго сервера. Итого: два письма с двумя разными IP-адресами.

ШАГ 2. Зайти на сервер по SSH

SSH — это способ управлять удалённым сервером из командной строки. Звучит страшно, но ниже всё по шагам.

Дима (Windows)

Windows 10/11 уже умеет SSH из коробки через PowerShell:

  1. Нажать Win + X и выбрать «Windows PowerShell» (или «Терминал»)
  2. Ввести команду (замени <IP> на IP из письма):
ssh root@<IP>

Пример: ssh root@185.12.34.56

  1. Первый раз выйдет вопрос вроде: Are you sure you want to continue connecting (yes/no)? — напечатать yes и нажать Enter
  2. Ввести пароль из письма. Внимание: когда вводишь пароль, символы не отображаются — это нормально. Просто введи и нажми Enter.
  3. Если всё ок — увидишь приветствие Ubuntu и строку вида root@ubuntu:~#

Если PowerShell не работает — скачать программу PuTTY (https://putty.org), запустить, в поле Host Name вставить IP, нажать Open, ввести логин root, затем пароль.

Алексей (Mac или Linux)

  1. Открыть Терминал (на Mac: Spotlight → “Terminal”)
  2. Ввести:
ssh root@<IP>
  1. Дальше так же: yes на предупреждение, пароль из письма.

ШАГ 3. Подготовка сервера

Эти команды нужно выполнить один раз на каждом сервере. Копируй целиком, вставляй в терминал, жми Enter, жди завершения.

3.1. Обновить систему

apt update && apt upgrade -y

Это может занять 2–5 минут. Дождись возврата строки root@...#.

3.2. Создать обычного пользователя (безопаснее, чем работать под root)

adduser deploy

Программа попросит придумать пароль для этого пользователя (придумай и запомни). Остальные поля (имя, телефон) — просто жми Enter.

usermod -aG sudo deploy

3.3. Настроить базовый файрвол (защита от чужих подключений)

ufw allow OpenSSH
ufw allow 3000/tcp
ufw --force enable

Это разрешает только SSH (управление сервером) и порт 3000 (наш будущий веб-интерфейс). Всё остальное — закрыто.

3.4. Установить Docker

Docker — это программа, которая позволяет запускать приложения в изолированных «контейнерах». Нам нужна для запуска Open WebUI.

Одна команда устанавливает всё автоматически:

curl -fsSL https://get.docker.com | sh

Дождись завершения (1–3 минуты). Потом:

usermod -aG docker deploy

Проверка:

docker --version

Должно вывести что-то вроде Docker version 26.x.x.

ШАГ 4. Установить Open WebUI

Open WebUI — это веб-интерфейс «свой ChatGPT». Устанавливается одной командой:

docker run -d \
  -p 3000:8080 \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

Что здесь происходит: - -d — запуск в фоне - -p 3000:8080 — интерфейс будет доступен на порту 3000 - -v open-webui:/app/backend/data — данные сохраняются на сервере (история чатов не потеряется при перезапуске) - --restart always — если сервер перезагрузится, Open WebUI запустится автоматически

Первый запуск скачивает образ (~500 МБ), это займёт 2–5 минут.

Проверка:

docker ps

Должна быть строка с open-webui и статусом Up.

Теперь открой в браузере: http://:3000

Должна появиться страница Open WebUI с предложением зарегистрироваться.

ШАГ 5. Первый вход — создать аккаунт администратора

  1. Открыть в браузере: http://<IP>:3000
  2. Нажать «Sign Up» (или «Зарегистрироваться»)
  3. Ввести имя, email (любой, даже несуществующий), придумать пароль
  4. Нажать «Create Account»

Важно: первый зарегистрировавшийся получает права администратора. Больше никто не сможет без разрешения зарегистрироваться (можно потом настроить).

ШАГ 6. Получить ключ DeepSeek и подключить его

6.1. Зарегистрироваться на platform.deepseek.com

  1. Открыть https://platform.deepseek.com
  2. Нажать Sign Up, создать аккаунт
  3. После входа перейти в API Keys (обычно слева в меню)
  4. Нажать «Create API Key»
  5. Скопировать ключ — он выглядит как: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Сохрани ключ прямо сейчас — после закрытия окна его не покажут снова. Если потеряешь — просто создай новый.

6.2. Пополнить баланс DeepSeek

  1. В личном кабинете platform.deepseek.com найти «Billing» или «Top Up»
  2. Пополнить на $10–20 картой (этого хватит на несколько месяцев при обычном использовании)

6.3. Подключить DeepSeek в Open WebUI

  1. Войти в Open WebUI: http://<IP>:3000
  2. Нажать на иконку своего аккаунта (справа вверху) → Admin Panel
  3. Перейти: Settings → Connections
  4. В разделе OpenAI API нажать кнопку «+» (добавить подключение)
  5. Заполнить: - URL: https://api.deepseek.com/v1 - API Key: вставить свой ключ sk-...
  6. Нажать Save (Сохранить)
  7. Open WebUI автоматически подтянет список доступных моделей

6.4. Выбрать модель по умолчанию

После сохранения подключения: 1. В верхней части интерфейса чата появится выпадающий список моделей 2. Выбрать deepseek-v4-flash — это основная рабочая лошадка. Дёшево, быстро, умно. 3. Для сложных задач (аналитика, код, длинные тексты) — выбирать deepseek-v4-pro

ШАГ 7. Первый запрос — проверка

  1. Нажать «New Chat»
  2. Убедиться что в списке моделей выбран deepseek-v4-flash
  3. Написать что-нибудь, например: Привет! Расскажи кто ты и что умеешь.
  4. Если пришёл ответ — всё работает.

Если что-то пошло не так — см. раздел «Частые проблемы» в конце гайда.

ШАГ 8. Минимальная безопасность

Что уже сделано

  • Файрвол ограничивает доступ (только SSH и порт 3000)
  • Первый зарегистрировавшийся — администратор, новые пользователи должны быть одобрены им

Что сделать сейчас

  • Запомни или запиши пароль от аккаунта в Open WebUI — восстановления через email нет (не настроено)
  • Ключ DeepSeek никому не передавай — он даёт доступ к балансу

Что сделать потом (необязательно, но желательно)

Закрыть порт 3000 от чужих IP (если хочешь доступ только с известных адресов):

# Закрыть публичный доступ к 3000
ufw delete allow 3000/tcp
# Разрешить только со своего IP (замени <ТВОй_IP>)
ufw allow from <ТВОй_IP> to any port 3000

Добавить HTTPS с красивым доменом — если хочешь заходить не по IP, а по адресу типа chat.mysite.ru. Для этого нужен свой домен. После его покупки ставится Caddy (простой веб-сервер), он автоматически выдаёт SSL-сертификат. Это — на потом, когда разберётесь с базовой версией.

ШАГ 9. Создать кастомных ассистентов

Это одна из главных фишек Open WebUI: можно создать несколько «режимов» с разными ролями. Например: «Помощник по контенту», «Маркетолог», «Личный ассистент».

  1. Нажать на иконку аккаунта → Admin Panel → Models (или через боковое меню Workspace → Models)
  2. Нажать «+ Create Model»
  3. Заполнить: - Name: например, Контент-мастер - Base Model: выбрать deepseek-v4-flash - System Prompt (системный промпт): это инструкция, которая определяет характер и задачи ассистента

Примеры системных промптов:

Для контент-мастера:

Ты — опытный контент-стратег. Помогаешь создавать тексты для соцсетей, блогов и рекламы. 
Пишешь по-русски, живым языком, без канцелярита. 
Когда получаешь тему — сначала уточняешь: для какой платформы, какая аудитория, какой тон.

Для маркетолога:

Ты — маркетинговый консультант с опытом в digital. 
Помогаешь с анализом рынка, позиционированием, рекламными стратегиями, воронками продаж.
Мыслишь данными, но объясняешь по-человечески.

Для личного помощника:

Ты — персональный ассистент. Помогаешь планировать задачи, писать письма, готовиться к встречам, 
разбираться в сложных вопросах. Краток, конкретен, дружелюбен.
  1. Нажать Save
  2. В чате выбрать созданного ассистента из списка моделей — и всё, он готов к работе.

Частые проблемы и что делать

Не открывается http://IP:3000

  1. Проверь что контейнер запущен: docker ps — должна быть строка с open-webui
  2. Если строки нет: docker start open-webui
  3. Проверь файрвол: ufw status — должна быть строка 3000/tcp ALLOW Anywhere
  4. Подожди 30–60 секунд после docker run — образ распаковывается

Ошибка при вводе ключа DeepSeek / модели не появляются

  1. Убедись что скопировал ключ полностью (начинается с sk-)
  2. Проверь URL: должно быть https://api.deepseek.com/v1 (именно с /v1 на конце)
  3. Проверь баланс на platform.deepseek.com — возможно, нужно пополнить
  4. После сохранения нажми кнопку обновления списка моделей (иконка рядом с полем URL)

Сервер не отвечает / SSH не подключается

  1. Подожди 10–15 минут после заказа — сервер ещё разворачивается
  2. Проверь IP из письма — иногда там два IP (используй тот, что помечен как «основной» или IPv4)
  3. Проверь пароль — он в письме, копируй с запасом (без лишних пробелов)

Сервер стал медленным / контейнер падает

free -h

Если строка Mem: показывает мало свободного (available меньше 500M) — перезапусти контейнер:

docker restart open-webui

Забыл пароль от Open WebUI

Придётся сбросить через базу данных. Либо пересоздать контейнер (данные сохранятся, но аккаунты — нет):

docker exec -it open-webui sqlite3 /app/backend/data/webui.db \
  "UPDATE user SET password='' WHERE role='admin';"
docker restart open-webui

После этого можно зайти без пароля и установить новый в настройках профиля.

Альтернатива: Telegram-бот вместо веб-интерфейса

Если нужен не веб-интерфейс, а бот прямо в Telegram — архитектура меняется. На сервере разворачивается Python-скрипт: python-telegram-bot принимает сообщения в Telegram, отправляет их в DeepSeek API через библиотеку openai (она совместима с DeepSeek), возвращает ответ в чат. VPS тот же, Docker не обязателен. Это немного сложнее в настройке (нужно создать бота через @BotFather в Telegram, получить токен, написать ~50 строк Python), но зато не нужно заходить на сайт — просто пишешь боту как другу. Open WebUI как дефолт рекомендуется потому что он не требует кода и сразу даёт полноценный интерфейс с историей, файлами и ассистентами.
