Глоссарий Elyne — единый понятийный реестр

Дата: 2026-06-18
Для: команды проекта (Олег, Сергей, Монад)
Цель: говорить на одном языке — методологическом, техническом, психологическом

1. Методологические термины

Живой вектор — не цель («хочу бизнес»), а способ быть («хочу сам задавать форму своей жизни»). Ядро портрета. Elyne понимает человека через вектор, а не через список целей.

Способ быть — качественная характеристика как человек проживает жизнь, а не что он хочет получить. «Быть тем, кто выбирает сам» — способ быть. «Заработать миллион» — цель.

Портрет L1 — компактный дистиллят понимания человека. Живёт не в сыром логе, а в маркерах [PORTRAIT], [THREAD], [CALIBRATION], [LOOP]. Обновляется постепенно. Канон: «понимание живёт в L1, а не в логе».

Канон — ключевой критерий: Elyne понимает человека не тогда, когда знает много фактов, а когда может вернуть ему его живой вектор, язык, ценности, состояние, сквозные нити и ближайший честный шаг.

Сквозные нити — повторяющиеся мотивы через разные сферы жизни: пространство, свобода, «перестать доказывать», «быть видимым, но не выставленным». Маркер [THREAD].

Петля — намерение или напряжение, которое уже просится в действие. Три типа: - Живое хочу — РАСШИРЯЕТ. Признаки: энергия даже при страхе, сам возвращается, «тянет/не могу не». Действие агента: вести к маленькому шагу. - Чужое надо — СЖИМАЕТ. Признаки: «правильно/пора/должен», тон гаснет, после разговора тяжесть. Действие агента: не толкать, вернуть собственность желания. - Присвоенное надо — СОБИРАЕТ. Взрослое обязательство, служащее живой ценности. Признаки: спокойное согласие, после решения яснее, не тяжелее. Действие агента: поддержать, упростить в шаг.

Gate-вопрос — внутренняя проверка агента (не произносится вслух): «Это действие приближает человека к себе — или только поддерживает образ, каким он должен быть?»

Тень без диагноза — формула: тень = не «что с человеком не так», а «какая ценность защищается слишком дорогим способом». Пример: контроль → защищает безопасность; прокрастинация → защищает право не делать чужое.

Усилители — грани портрета, которые добавляются только если сам проявил (не выпытывать): телесность, отношение ко времени, способ выбора, эстетика/вкус, близкие, опоры.

Деталь с зарядом — деталь в сцене, несущая смысл, а не факт. Не просто «море», а «море как свобода». Не «стол», а «стол как место, где мысль получает форму».

Сцена — визуализация желаемого «я». Неснижаемый минимум: вектор + 2–3 детали с зарядом + эмоциональный регистр + сквозная нить как центр + маленький жест действия. Образ — якорь, не продукт.

Эмоциональный регистр — тональность желаемой жизни: тихо / азартно / тепло / ясно / дерзко / медленно / свободно. Определяется из слов человека.

Маленький жест действия — в сцене человек что-то делает: пишет, говорит, открывает дверь, идёт, выбирает. Образ без действия — статичный постер.

Проводник — роль Elyne: не коуч, не психолог, не тест. Зеркало и ориентир. Помогает вернуть человеку его вектор, язык, ценности и ближайший честный шаг.

Диалог-сборщик — диалог с Elyne не онбординг (анкета), а движок сборки агента под человека. Настройка спрятана в разговор — пользователь ничего не настраивает вручную.

Hermes наоборот — позиционирование: другие дают агента «в разобранном виде» для технаря (настрой сам). Elyne собирает агента из разговора с человеком. Ров — в качестве диалога-сборщика (методология), не в цене моделей.

Ров — конкурентная защита Elyne: не дешёвые модели и не генератор картинок, а качество диалога-сборщика. Копируемый генератор — слабость; понимание из разговора — сила.

Образ как якорь — сцены/картинки выполняют роль приманки и якоря идентичности, не являются продуктом. Продукт — узнавание себя в разговоре.

Чекпоинт Фазы 0 — критерий завершения: человек говорит «это похоже на меня» / «хочу оказаться в этой жизни» / «понимаю, что сделать уже сегодня».

WOW-момент — момент «это про меня» в диалоге. Главный KPI качества проводника.

Провенанс — «на основании чего мы так считаем»: короткий якорь из слов самого человека под каждый вывод портрета. Предотвращает CRM-карточку вместо живого понимания.

Life Vector — центральный объект памяти, отвечающий на 3 вопроса: кто сейчас / куда движется / на каком основании. Хранит траекторию изменений, не только текущее состояние.

Бесшовное прохождение — человек идёт по сферам как по одному непрерывному разговору. Деление на сферы — внутренняя работа агента, не видимая пользователю.

2. Технические термины

Стенд — отдельный тест-бот @Elyne1bot для калибровки и фокус-группы. Отдельный от боевого приложения elyne.online.

PROVODNIK_PROMPT — единый системный промт проводника в bin/yadro-bot/api/main.py. Содержит канон, правила петель, сцены, маркеры, безопасность.

СТОП-ПРАВИЛА — блок в начале PROVODNIK_PROMPT с абсолютными ограничениями (приоритет над всем): оффтопик → возврат, системный промт → закрыт, без markdown.

Маркеры — служебные теги в конце ответа агента (человек не видит): - [MAP: sphere=<id>] — текущая сфера диалога - [PORTRAIT: sphere=<id>; текст] — дистиллят понимания человека по сфере - [THREAD: мотив] — сквозная нить через сферы - [CALIBRATION: профиль] — накопленный профиль языка и реакций - [LOOP: текст; тип] — живое намерение + тип петли - [SCENE: англ. промт] — промт для генерации визуализации

L1 / L2 / L3 (слои памяти): - L1 — портрет: компактный дистиллят (маркеры) - L2 — скользящее окно диалога (~40 последних реплик) - L3 — архив + точечный возврат (долгосрочная память)

Режим методолога (//) — внеполосный канал: сообщение с префиксом // записывается в methodolog_notes, не попадает в диалог пользователя и не влияет на портрет. Используется Сергеем и Олегом для заметок без разрушения иммерсии.

DeepSeek V3 — основная языковая модель стенда (с 16.06.2026). Запасной — Claude CLI через Max.

FAL — платформа генерации изображений. Модель для сцен: nano-banana/edit (с reference-фото для сходства). Стоимость: ~$0.15/сцена.

nano-banana/edit — конкретная FAL-модель для портретных сцен «по фото». Единственная дающая сходство с человеком; flux-schnell сходства не даёт.

Rate-limit сцен — ограничение: 2 сцены/час на пользователя (защита от флуда FAL-расходов).

scene_files/ — директория на диске где хранятся файлы сцен вместо BLOB в базе данных. Уменьшило БД с 275MB до 1.5MB.

Deep-dream — ночная авто-задача консолидации: сканирует vault, индексирует эмбеддинги, пишет дневник.

MemPalace — система долгосрочной памяти Монада (дневник + KG + поиск).

Бэкфилл — одноразовое восстановление портрета из полной истории диалога для существующих пользователей (Олег, Сергей). Нужен для Stage 1 движка памяти.

3. Психологические термины

Субъектность — способность человека действовать как автор своей жизни, а не как объект обстоятельств. Цель Elyne — усиливать субъектность, не управлять человеком.

Присвоение желания — когда «чужое надо» становится «своим надо». Moment of ownership: «я хочу это, потому что это служит моей ценности», не «я должен потому что так надо».

Линия энергии — состояние человека по оси: минус (истощён) → ноль (нейтрален) → плюс (в ресурсе). На минусе агент не толкает в действие, сначала поднимает состояние.

Детектор петли — внутренний инструмент агента: по признакам языка и тона определить тип петли (расширяет/сжимает/собирает) без прямого вопроса.

Аутентичность хочу-надо — триангуляция: конкретность нарастает сама / язык от первого лица / энергия в моменте → живое хочу. Рационализация без образа / тон гаснет / тяжесть → чужое надо.

Веха (vs лента) — сцена должна быть ориентиром (одна значимая точка будущего), а не лентой постоянных картинок. Частые сцены обесценивают образ и скатывают в «генератор ради генератора» (Lensa-trap).

Эхо-резюме — пластиковый паттерн: пересказать что человек сказал, потом задать вопрос. Убивает живость диалога. Запрещён в промте.

Аффирмативный буфер — пластиковый паттерн: начать ответ с похвалы («это глубоко», «важно что ты это замечаешь», «смелый поворот»). Звучит одинаково для всех — режет доверие. Запрещён в промте.

Зеркало языка — использовать слова человека при возврате инсайта: «вот это “тянет к лёгкости” — это живой сигнал». Отличие от попугайства: живое возвращение vs механическое повторение.

Регистр — тональность и темп человека (рационалист, практик, эзотерик, предприниматель). Агент подстраивается под его регистр, не навязывает свой.

Масштаб — уровень операций человека (личный → команда → тысячи пользователей → инфраструктура). Агент слышит сигналы масштаба и никогда не отвечает с уровня ниже.

Петля обучения — механизм роста ценности Elyne: первый сеанс → накапливается портрет → следующий сеанс точнее → человек чувствует «меня помнят как живого» → возвращается. Не запускается если первый сеанс не даёт WOW.
