Суть архитектуры

Три слоя поверх обычного ReAct-агента:

  1. Object — то, что агент делает (думает → действует → наблюдает)
  2. Monitor — непрерывно считает 4 метрики: прогресс к цели, связность шагов, точность уверенности, расход токенов
  3. Control — конечный автомат из 4 режимов: Normal / Careful / Exploratory / Reflective

Переключение режимов автоматическое — по трешхолдам мониторинга. Например: 2 провала инструмента → Reflective mode (явная самокритика перед следующим шагом).

Результат: +31% завершения задач, −19% токенов. Причём Open Source модели выиграли больше (+34%), чем GPT-4o/Claude (+27-31%) — мета-рассуждение компенсирует слабую модель.

Semantic retrieval mempalace_search ✓ есть

Что можно добавить прямо сейчас (без кода)

1. Behavioral rule: failed tool → Reflective pause

Сейчас: инструмент упал дважды → я ретраю по инерции.
Нужно: при 2+ consecutive failures — явно останавливаюсь и задаю себе вопросы: - «Что конкретно не работает?» - «Есть ли обходной путь?» - «Стоит ли это продолжать без Олега?»

Это поведение, можно закрепить в personas/boris.md как правило.

2. Pre-task episode retrieval

Сейчас: начинаю задачу с нуля.
Нужно: перед нетривиальной задачей — mempalace_search по ключевым словам задачи, смотрю похожие прошлые эпизоды. Уже были похожие грабли? Учитываю сразу.

3. Progress checkpoint на шаге 5+

При многошаговой задаче (>5 tool calls) — явная проверка: - «Я двигаюсь к исходной цели или съехал?» - «Сколько уже потрачено токенов/денег?»

Что стоит добавить (небольшой код, ~1 вечер)

Automatic mode switching

Normal → Careful: когда платное действие / публичный post / удаление файла
Normal → Exploratory: новый тип задачи, нет прецедентов в diary
Any → Reflective: 2+ failed tools / coherence упала / противоречивые данные

Можно реализовать как hook в .claude/hooks/ — проверяет паттерны и добавляет preflight warning в tool call.

Composite score в diary

После сложных задач автоматически пишу в diary:

SCORE: P=0.8 C=0.7 K=0.9 R=0.6 → composite=0.75

Накопленная статистика → видно где я стабильно слабею.

Главный инсайт для нас

Мониторинг один — даёт +11%.
Адаптация одна — даёт +15%.
Вместе — 31%. Синергия сверх суммы.

У нас в Monad сейчас есть обе части по отдельности: - MemPalace = memory + retrieval (есть) - Diary = monitoring (частичный) - Режимы работы = нет явного автоматического переключения

Добавить автоматическое переключение режимов на основе паттернов — это самый высокий ROI из всего что описано в статье.
