Арендуй сервер (VPS)

Нужен виртуальный сервер под Ubuntu. Минимальные характеристики — 2 ядра CPU, 4 ГБ RAM, 40 ГБ SSD. Этого хватит на старт.

Совет: бери Ubuntu 24.04 LTS. При создании — сразу добавь SSH-ключ, не пароль. Ниже объясню как.

Создай SSH-ключ на своём ноутбуке

Открой Terminal (Mac) или PowerShell (Windows) и выполни:

ssh-keygen -t ed25519 -C "ты@email.com"
# Нажми Enter три раза (путь по умолчанию, без пароля)

# Посмотреть публичный ключ — его вставишь в настройки сервера
cat ~/.ssh/id_ed25519.pub

Скопируй вывод (начинается с ssh-ed25519 AAAA...) и вставь в поле «SSH-ключ» при создании сервера.

После создания сервера подключишься командой: ssh root@IP-СЕРВЕРА

Первоначальная настройка Ubuntu

Подключись к серверу и выполни базовую настройку. Это займёт 5 минут.

# Обновляем систему
apt update && apt upgrade -y

# Устанавливаем базовые утилиты
apt install -y curl wget git unzip ffmpeg python3-pip python3-venv build-essential

# Создаём нового пользователя (замени "oleg" на своё имя)
adduser oleg
usermod -aG sudo oleg

# Копируем SSH-ключ для нового пользователя
rsync --archive --chown=oleg:oleg ~/.ssh /home/oleg

# Выходим и заходим под новым пользователем
exit
ssh oleg@IP-СЕРВЕРА

Базовая защита

# Устанавливаем файрвол
sudo ufw allow ssh
sudo ufw allow 443
sudo ufw enable

# Защита от перебора паролей
sudo apt install -y fail2ban
sudo systemctl enable fail2ban --now
Зачем это? Без базовой защиты на свежий сервер в интернете приходят боты и пробуют взломать. Fail2ban автоматически блокирует подозрительные IP.

4
Anthropic API ключ

Это главный ключ — без него агент не работает.

  1. Зайди на console.anthropic.com
  2. Зарегистрируйся (нужна карта — Visa/Mastercard, виртуальная тоже подойдёт)
  3. Иди в раздел API Keys → Create Key
  4. Скопируй ключ — он начинается с sk-ant-...
Важно! Ключ показывается только один раз. Скопируй и сохрани в надёжное место. Никому не передавай — это как пароль от банка.

Примерная стоимость

МодельВходящие токеныИсходящие токеныРеальная стоимость
Claude Sonnet 4.6 (быстрый)$3 / 1M токенов$15 / 1M токенов~$5-15/мес при активном использовании
Claude Opus 4.7 (умный)$15 / 1M токенов$75 / 1M токенов~$20-50/мес
Совет: начни с Sonnet — он в 5 раз дешевле и для большинства задач ничем не хуже. На Opus переходи только для сложных стратегических задач.
5
Установка Claude Code

Claude Code — это официальный инструмент от Anthropic. Агент работает именно через него.

# Устанавливаем глобально
npm install -g @anthropic-ai/claude-code

# Задаём переменные окружения
echo 'export ANTHROPIC_API_KEY="sk-ant-ТВОЙ-КЛЮЧ"' >> ~/.bashrc
source ~/.bashrc

# Проверяем
claude --version
Что это такое? Claude Code — CLI (программа в командной строке), которая общается с моделью Anthropic. Твой агент — это Claude Code, который умеет читать файлы, запускать команды, общаться через Telegram.
6
Создай Telegram-бота

Telegram — интерфейс через который ты будешь общаться с агентом.

  1. Открой Telegram и найди @BotFather
  2. Напиши /newbot
  3. Придумай имя (например: Мой ассистент)
  4. Придумай юзернейм (заканчивается на bot, например: eldor_ai_bot)
  5. Получишь токен вида 123456789:AABBcc... — это твой BOT_TOKEN
Важно: узнай свой Telegram ID. Напиши боту @userinfobot — он ответит твоим числовым ID. Запиши его — это TELEGRAM_USER_ID, агент будет принимать команды только от тебя.

Установка ClaudeClaw (обёртка для бота)

ClaudeClaw — это готовая обвязка, которая соединяет Claude Code с Telegram. Устанавливается как плагин.

# Создаём папку проекта
mkdir ~/my-agent && cd ~/my-agent
git init

# Инициализируем
claude  # первый запуск — авторизует аккаунт через браузер
Совет: при первом запуске Claude Code откроет ссылку для авторизации. Открой её на компьютере, войди в свой аккаунт Anthropic. Авторизация привязана к API ключу.
7
Файл конфигурации .mcp.json — расширения агента

MCP (Model Context Protocol) — это «расширения» для агента. Каждый MCP-сервер даёт агенту новую суперсилу: поиск в интернете, работу с файлами, подключение к Telegram и т.д.

Создай файл ~/my-agent/.mcp.json:

{
  "mcpServers": {
    "web-search": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": {
        "BRAVE_API_KEY": "ТУТ_КЛЮЧ_BRAVE"
      }
    },
    "filesystem": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/oleg/my-agent"]
    },
    "memory": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    }
  }
}

Популярные MCP-расширения

РасширениеЧто умеетКлюч нужен?
server-brave-searchПоиск в интернетеДа (Brave API, бесплатный тариф есть)
server-filesystemЧитать/писать файлыНет
server-memoryДолгосрочная памятьНет
server-githubРабота с GitHub репозиториямиДа (GitHub token)

Brave Search API: зарегистрируйся на api.search.brave.com. Бесплатный тариф = 2000 запросов в месяц — для личного агента хватит.
8
CLAUDE.md — личность агента

Это главный файл — «мозг и характер» твоего агента. Всё что ты напишешь здесь, агент будет помнить и следовать этому при каждом ответе.

Создай файл ~/my-agent/CLAUDE.md:

# Мой персональный ассистент

## Кто я
Я — персональный ассистент Эльдара. Помогаю планировать день,
отвечаю на вопросы, нахожу информацию, напоминаю о задачах.

## Тон
- Отвечаю на русском языке
- Короткие понятные ответы, без воды
- Обращаюсь на "ты"
- Без официального тона — как умный друг

## Что умею
- Поиск информации в интернете
- Работа с файлами на сервере
- Напоминания через Telegram
- Анализ документов и текстов

## Правила
- Личные данные — строго конфиденциально
- Перед дорогими операциями (AI-генерация и т.д.) спрашиваю разрешение
- Если не уверен — уточняю, не угадываю
Это живой документ. Добавляй в него правила по мере того как замечаешь, что агент делает что-то не так. Например: «Олег хочет дайджест новостей без политики» — добавь это правило и агент запомнит навсегда.

Запуск как постоянный сервис (systemd)

Чтобы агент работал всегда — даже когда ты не подключён к серверу — нужно запустить его как системный сервис.

Создай файл сервиса

sudo nano /etc/systemd/system/my-agent.service

Вставь это (замени eldor на своё имя пользователя):

[Unit]
Description=My AI Agent
After=network.target

[Service]
Type=simple
User=eldor
WorkingDirectory=/home/eldor/my-agent
Environment=ANTHROPIC_API_KEY=sk-ant-ТВОЙ_КЛЮЧ
Environment=TELEGRAM_BOT_TOKEN=123456789:AABBcc...
Environment=TELEGRAM_USER_ID=123456789
ExecStart=/usr/local/bin/claude -p /home/eldor/my-agent --permission-mode bypassPermissions
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

Запускаем

# Загружаем конфиг
sudo systemctl daemon-reload

# Включаем автозапуск при старте сервера
sudo systemctl enable my-agent

# Запускаем сейчас
sudo systemctl start my-agent

# Проверяем что работает
sudo systemctl status my-agent

# Смотреть логи в реальном времени
journalctl -u my-agent -f
Если в статусе написано Active: active (running) — агент запущен и слушает сообщения от тебя в Telegram!
Если что-то пошло не так: посмотри логи командой journalctl -u my-agent -n 50 — там будет описание ошибки.

Голосовые сообщения

Агент может отвечать голосом (синтез речи) и понимать голосовые сообщения (распознавание речи).

Синтез речи — edge-tts

# Устанавливаем
pip install edge-tts

# Проверяем русские голоса
edge-tts --list-voices | grep ru-RU

# Лучший мужской голос — Дмитрий
edge-tts --voice ru-RU-DmitryNeural --rate=-10% --pitch=-2Hz \
  --text "Привет! Это твой ассистент" --write-media /tmp/test.mp3

# Воспроизвести (проверка)
ffplay -nodisp /tmp/test.mp3

Распознавание речи — faster-whisper

# Устанавливаем
pip install faster-whisper

# Тестируем (Python)
python3 -c "
from faster_whisper import WhisperModel
model = WhisperModel('small', device='cpu')
segments, _ = model.transcribe('/tmp/test.mp3', language='ru')
for s in segments:
    print(s.text)
"
Модели Whisper: tiny (быстрый, менее точный), small (оптимальный для сервера), medium (точнее, нужно больше RAM), large-v3-turbo (лучший результат, нужно 8+ ГБ RAM)
Совет: для сервера с 4 ГБ RAM используй модель small — хорошая точность для русского языка при минимальных требованиях.

GitHub — хранение и синхронизация

Храни файлы своего агента на GitHub — это и резервная копия, и возможность работать с кодом с разных устройств.

# Настраиваем git
git config --global user.name "Твоё имя"
git config --global user.email "ты@email.com"

# Создаём репозиторий на github.com (через сайт), затем связываем
cd ~/my-agent
git remote add origin https://github.com/твой-логин/my-agent.git

# Файл .gitignore — не загружаем секреты!
cat > .gitignore << 'EOF'
.env
secrets/
*.key
*.pem
node_modules/
__pycache__/
EOF

# Первый коммит
git add CLAUDE.md .mcp.json
git commit -m "initial agent setup"
git push -u origin main
Никогда не загружай на GitHub: файлы с паролями, API ключами, токенами бота. Используй .gitignore и храни секреты в отдельном зашифрованном файле.
