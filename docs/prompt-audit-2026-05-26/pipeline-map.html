Elyne Prompt Pipeline Map

Audit date: 2026-05-26 | Source: code scan + admin DB

Flow 1: Profile Summary

Trigger: GenerateProfileAnalysisJob (after onboarding completion)

1. GenerateProfileSummaryAction::execute(Card)
   ├── placeholderService.getOnboardingAnswers(card)
   ├── placeholderService.getSelectedClothingStyles(card)
   └── textAi.generateProfileSummary(gender, age, answers, styles, marital_status)
       ├── ADMIN PROMPT: profile_summary_system (ID=15) [13239 chars]
       │   Placeholders: {gender}, {age}, {profile_extra}, {onboarding_answers}, {clothing_styles}
       │   FALLBACK (code): "Ты — психолог и консультант по персональному брендингу..."
       ├── CODE APPENDED: "\n\nВерни строго JSON без markdown: {\"summary\": \"...\"}"
       └── OpenRouter → maxTokens=3000 → Card.profile_summary + Card.profile_summary_prompt

2. GenerateAffirmationAction::execute(Card)
   └── textAi.generateAffirmation(resolvedPrompt)
       ├── ADMIN PROMPT: affirmation (ID=16) [618 chars]
       │   Placeholders: (TBD — needs micro analysis)
       └── OpenRouter → Card.affirmation_text + Card.affirmation_prompt

Flow 2: First Scene (Three Angles)

Trigger: SelectSphereJob → GenerateThreeAnglesJob (after profile photo + sphere selection)

PRE-REQUISITES:
  - Card.profile_summary must exist (from Flow 1)
  - Card.selectedSphere must be set (from SelectSphereJob)
  - ClothingChoiceJob must complete (wait via WaitsForClothingChoice concern)

1. GenerateThreeAnglesJob::handle()
   ├── placeholderService.resolveForSphere(
   │     prompt: ADMIN three_angles_scene meta_prompt,   ← type=three_angles_scene (NOT IN DB — may use field_scene?)
   │     card, sphere, relativeIds, questionIds)
   │   OR falls back to: type=field_scene per sphere (if three_angles_scene missing)
   │   Placeholders: {profile_summary}, {onboarding_answers}, {sphere_title},
   │                 {sphere_short}, {sphere_slug}, {sphere_definition},
   │                 {relatives_photos[]}, {micro_adjustment_answers}, {chosen_clothing_style}
   │
   ├── textAi.generateThreeAngles(resolvedPrompt)
   │   ├── SYSTEM PROMPT: none (systemMessage=null by default)
   │   ├── CODE APPENDED: JSON schema hint (3 scenes with title/short_description/detailed_description)
   │   ├── OpenRouter → maxTokens=4000, maxRetries=3
   │   └── STUB FALLBACK: 3 stubs if all retries fail
   │
   └── FOR EACH of 3 scenes:
       ├── GeneratedScene::create(title, short_description, detailed_description, meta_prompt_text)
       └── CreateScenePhotoAction::execute(card, sphere, scene, resolvedPrompt, relativeData, clothingBlock)
           ├── BUILD FAL PROMPT (⚠️ BUG — missing getImageInstructions!):
           │   scene.detailed_description
           │   + [relatives instructions if hasRelatives]
           │   + clothingBlock (if not empty)
           │   ← MISSING: getImageInstructions() / image_instructions
           └── GenerateImageJob → FAL nano-banana-pro/edit

Flow 3: First Post-Payment Scene (GenerateFirstPostPaymentSceneJob)

Trigger: payment confirmed → GenerateFirstPostPaymentSceneJob

Similar to Flow 2 but dispatches single scene.
Uses same CreateScenePhotoAction — inherits same ⚠️ BUG (no image_instructions).

Flow 4: Sphere Scene (Initial)

Trigger: User opens sphere, picks scene → DispatchSpherePhotoAction(base_source=profile_photo)

1. DispatchSpherePhotoAction::execute(base_source='profile_photo')
   └── promptService.buildFinalPromptText(scene.detailed_description, userScene, userComment)
       ├── scene.detailed_description (scene_prompt)
       ├── + image_suffix from ADMIN (per sphere if exists, else profile_photo suffix)
       ├── + ADMIN image_instructions (ID=12) [5472 chars, FALLBACK cp-01]
       ├── + "Пожелание: {comment}" if comment present
       └── + clothingBlock from placeholderService
       → GenerateImageJob → FAL nano-banana-pro/edit (userPhotoUrl=selfie)

Flow 5: Sphere Scene Regeneration (No Comment)

Trigger: User regenerates without comment → DispatchSpherePhotoAction(base_source=previous_generation, no comment)

Replay iter=1 final_prompt_text verbatim.
If iter=1 has no final_prompt_text (legacy): rebuild from scene_prompt_text + relatives + clothing.
→ GenerateImageJob → FAL (userPhotoUrl=selfie)

Flow 6: Wish/Comment Flow

Trigger: User regenerates WITH comment → DispatchSpherePhotoAction → InterpretWishAndGenerateJob

1. textAi.classifyWishComment(userComment, originalScene)
   ├── CODE PROMPT: [fully hardcoded cp-10]
   │   "Текущая сцена: {currentScene}\nКомментарий: \"{userComment}\"\n..."
   └── OpenRouter → maxTokens=50 → LOCAL_EDIT or CONTEXT_SHIFT

2a. If LOCAL_EDIT:
    ├── PromptGenerationService::buildCommentOnlyPrompt(comment, hasRelatives, fieldNumber, isProfilePhoto)
    │   "Пожелание: {comment}"
    │   + [relatives instructions if hasRelatives]
    │   + image_suffix (sphere or profile_photo)
    │   + ADMIN image_instructions (ID=12)
    ├── CODE APPENDED: LOCAL_EDIT guard [cp-04]
    │   "ЭТО ЛОКАЛЬНАЯ ПРАВКА: не меняй лицо..."
    ├── + clothingBlock
    └── GenerateImageJob → FAL (baseGenerationUrl = previous image, userPhotoUrl=null)

2b. If CONTEXT_SHIFT:
    ├── ADMIN wish_scene (ID=34) resolved via resolveForSphere()
    │   Placeholders: {sphere_title}, {sphere_definition}, {profile_summary}, {onboarding_answers}
    ├── CODE PREPENDED: generateWishScene context block [cp-08]
    │   (ОРИГИНАЛЬНАЯ СЦЕНА + ПОЖЕЛАНИЕ + ИНСТРУКЦИЯ + ПРЕЕМСТВЕННОСТЬ + АДМИН-МЕТАПРОМПТ)
    ├── OpenRouter → maxTokens=2000 → enrichedScene (detailed_description)
    ├── finalPrompt = enrichedScene + getImageInstructions() + clothingBlock
    └── GenerateImageJob → FAL (userPhotoUrl=selfie, baseGenerationUrl=null)

Flow 7: Photo Session (Explore)

Trigger: User opens photo session mode → CreatePhotoSessionVariantJob (via DispatchPhotoSessionAction)

1. placeholderService.resolveWithVariants(
      prompt: ADMIN photo_session (ID=20) [14184 chars],
      card, sphere, relativeIds, priorVariants, userComment)
   Placeholders: {profile_summary}, {onboarding_answers}, {sphere_title},
                 {relatives_photos[]}, {micro_adjustment_answers},
                 {chosen_clothing_style}, {previously_generated_variants}, {user_comment}

2. textAi.generatePhotoSessionScene(resolvedPrompt, originalFullPrompt, priorVariants)
   ├── CODE PREPENDED: photo_session context block [cp-09] (if originalFullPrompt exists)
   │   (ОРИГИНАЛЬНЫЙ ПРОМПТ + УЖЕ СНЯТЫЕ ВАРИАНТЫ + ИНСТРУКЦИЯ КОДА + АДМИН-МЕТАПРОМПТ)
   └── OpenRouter → maxTokens=2500 → new variant detailed_description

3. Build FAL prompt:
   variant.detailed_description
   + getImageInstructions() [from ADMIN image_instructions (ID=12)]
   + clothingBlock
   → GenerateImageJob → FAL (userPhotoUrl=selfie)

Flow 8: Scene Affirmation

Trigger: GenerateSceneAffirmationJob (after FAL image completes)

1. Sphere::byFieldNumber(userScene.field_number)
2. placeholderService.resolveScene(
      prompt: ADMIN scene_affirmation (ID=19) [388 chars],
      userScene, sphere)
   Placeholders: {scene_title}, {scene_short_description}, {profile_summary}, {onboarding_answers}

3. textAi.generateSceneAffirmation(resolvedPrompt)
   ├── CODE APPENDED: JSON schema hint {affirmation_text: "..."}
   └── OpenRouter → maxTokens=400 → UserScene.affirmation_text

Flow 9: AI Questionnaire Question

Trigger: GenerateAiQuestionnaireQuestionAction::handle() (on first sphere Q3 open)

1. ADMIN ai_questionnaire_question PER QUESTION (ai_metaprompt on QuestionnaireQuestion model)
   ↓ per-question meta prompt, each unique for each sphere's Q3

2. placeholderService.resolveForSphere(question.ai_metaprompt, card, sphere)
   Placeholders: {sphere_title}, {profile_summary}, {gender}, {micro_adjustment_answers}

3. textAi.generateAiQuestionnaireQuestion(resolvedMetaprompt)
   ├── SYSTEM PROMPT: ADMIN ai_questionnaire_question system prompt (ID=21) [356 chars]
   │   FALLBACK: "Ты ассистент. На основе метапромпта сформулируй ОДИН уточняющий вопрос."
   ├── CODE APPENDED: JSON schema hint {question: "..."}
   └── OpenRouter → maxTokens=400 → UserQuestionnaireResponse.ai_generated_question_text

Flow 10: Scene Variants (GenerateScenesAction)

Trigger: GenerateScenesAction (API call for generating scene options)

1. ADMIN field_scene per sphere (IDs 2-11, 33) resolved via resolveForSphere()
   Placeholders: full set including {profile_summary}, {onboarding_answers}, {sphere_*},
                 {relatives_photos[]}, {micro_adjustment_answers}, {chosen_clothing_style}

2. Anti-duplication block PREPENDED [cp-05]:
   "ВАЖНО: для этой сферы пользователю уже были предложены: {existing_titles}..."

3. textAi.generateSceneVariants({resolved_meta_prompt, count, field_number})
   ├── SYSTEM PROMPT: ADMIN scene_system (ID=32, with fallback cp-11)
   │   Template: "Ты — креативный сценарист... Сгенерируй {count} вариант(а/ов)"
   ├── CODE: {count} resolved via str_replace in systemMessage
   └── OpenRouter → maxTokens=3500 → array of scene variants

Flow 11: Sphere Selection

Trigger: SelectSphereJob (after profile summary generated)

1. ADMIN sphere_selector prompt (if exists in DB — NOT FOUND in fetched records)
   + Placeholders: {profile_summary}, {onboarding_answers}, {spheres_catalog}

2. textAi.selectSphere(resolvedPrompt, validSlugs)
   ├── CODE APPENDED: "Верни JSON: {\"sphere\": \"slug\"}" style hint
   └── OpenRouter → sphere slug → Card.selected_sphere_id

Flow 12: Clothing Choice

Trigger: DispatchSphereClothingChoiceAction → ChooseClothingStyleJob

1. placeholderService.resolveForClothingChoice(
      prompt: some admin prompt (sphere clothing choice),
      card, sphere, clothingStyles)
   Placeholders: {profile_summary}, {user_clothing_styles}, {sphere_title}

2. textAi.chooseClothingStyle(resolvedPrompt, userStyles)
   ├── maxRetries=3
   └── OpenRouter → {style: "slug", reason: "..."} → CardSphereClothingChoice

Flow 13: Profile Summary Refresh

Trigger: RefreshProfileSummaryJob

Uses ADMIN profile_summary_system (ID=15) via resolveForRefresh():
- {previous_profile_summary} placeholder used
- OpenRouter → updated Card.profile_summary

Image Assembly Order (Final FAL Prompt)

For most flows (Flows 3-5), the FAL prompt is built as:

[scene.detailed_description / enrichedScene]
  + [image_suffix per sphere (from ADMIN field_scene.image_suffix)]
  + [ADMIN image_instructions (ID=12)]
  + ["Пожелание: {comment}" if comment]
  + [clothingBlock (from ClothingStyle.description_male/female)]
  + [relatives instructions if hasRelatives]

Exception (⚠️ BUG): CreateScenePhotoAction (used in Flow 2 + 3):

[scene.detailed_description]
  + [relatives instructions if hasRelatives]
  + [clothingBlock]
  ← MISSING image_instructions!

Prompt length cap: FAL cuts off at 5000 characters (FalAiService::generateImage())
