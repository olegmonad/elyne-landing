Admin vs Code: Сравнительная таблица промптов

Дата аудита: 2026-05-26

Принцип разделения

Уровень Где живёт Редактируется кем Назначение
Admin-editable generation_prompts таблица Олег через elyne.online/admin Содержательные промпты — что говорить LLM о контексте, сфере, персонаже
Code-only Файлы PHP (Services, Jobs, Actions) Денис через код Структурные промпты — JSON-схемы, safety guards, context blocks

Правило: JSON schema никогда не выносится в admin — если admin сломает схему, JSON-парсинг упадёт молча (зафиксировано как feedback_ai_prompt_json_schema_code_only).

Критические несоответствия (⚠️ BUGS)

BUG-01: CreateScenePhotoAction не добавляет image_instructions

Severity: HIGH
Файл: app/Actions/Cards/CreateScenePhotoAction.php
Затронутые флоу: Three-angles first scene, Post-payment first scene
Симптом: FAL получает промпт без face preservation / quality instructions
Ожидаемо: getImageInstructions() должен добавляться так же, как в buildFinalPromptText()
Фактически: Промпт = scene.detailed_description + relativesIfPresent + clothingBlock (без image_instructions)

BUG-02: ai_questionnaire_question system prompt (ID=21) содержит опечатку

Severity: LOW
Текст: “вот что изместно о пользователе” → должно быть “известно”
Используется: как system prompt в generateAiQuestionnaireQuestion()

NOTE-01: three_angles_scene тип не найден в DB

Статус: Возможно не создан или тип не используется — код в GenerateThreeAnglesJob запрашивает type=three_angles_scene, если не находит — job завершается с ошибкой. Нужно проверить, что в DB есть запись с этим типом или код fallback’ает на field_scene.

UPD: Проверить — возможно GenerateThreeAnglesJob напрямую использует field_scene (в коде запрос: where('type', GenerationPromptType::ThreeAnglesScene->value)).

NOTE-02: scene_system / sphere_selector не найдены в fetched records

Статус: ID=32 и potential sphere_selector тimed out — нужна проверка при стабильном сервере.
