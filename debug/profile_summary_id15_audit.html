## FIRST SCENE IDENTITY CONTINUITY ADDITIONS

Character Profile должен описывать одного устойчивого человека.

Не просто суммируй ответы пользователя. Определи устойчивое ядро личности, которое будет сохраняться в первой сцене и во всех последующих сценах.

Профиль должен фиксировать:
- внутренние мотивы;
- эмоциональное направление;
- способ проявления;
- визуальную идентичность;
- уровень жизни;
- тип среды;
- социальный сигнал;
- Key Answer Locks.

## Key Answer Locks

Key Answer Locks — это ответы пользователя, которые ОБЯЗАНЫ проявиться в первой сцене.

В этот блок должны попасть:
- главный приоритет пользователя;
- желаемая среда;
- желаемый уровень жизни;
- способ проявления;
- визуальный образ;
- социальный сигнал;
- режим генерации;
- фокус усиления.

Если сцена не содержит хотя бы 3 Key Answer Locks, такая сцена считается слабой и должна быть пересобрана на следующем этапе.

## No Synthetic Personality

Не придумывай отсутствующие данные.

Запрещено:
- выдумывать психологические травмы;
- ставить диагнозы;
- придумывать скрытые мотивации;
- создавать fake archetype;
- делать generic self-help profile.

Все выводы должны вытекать только из реальных ответов пользователя.


## Visual Identity Interpretation

Выбранные стили одежды не являются прямым списком вещей, которые нужно надеть на пользователя.

Интерпретируй выбранные стили как визуальное направление личности:
- какой человек по ощущению;
- насколько он собранный или расслабленный;
- насколько он современный;
- насколько образ смелый или сдержанный;
- как стиль связан с его жизненным вектором;
- какие элементы стиля являются главными, а какие второстепенными.

В поле Visual Identity опиши не только предметы одежды, а способ визуального присутствия человека.

Если выбрано несколько стилей, не перечисляй их механически. Собери общий визуальный вектор.

Пример хорошей интерпретации:
«Современный городской образ с расслабленной уверенностью: чистые формы, актуальные пропорции, качественные материалы, минимум демонстрации, но заметное чувство вкуса.»

Пример плохой интерпретации:
«Носит кашемировый свитер, бежевые брюки и лоферы.»

## Visual Identity Weight Control

Visual Identity должна описывать способ визуального присутствия человека, но не должна подменять его жизненный сценарий.

Стиль одежды может помогать понять:
- степень собранности или расслабленности;
- мягкость или выразительность;
- отношение к телу;
- отношение к вниманию;
- уровень формальности;
- визуальный вкус;
- тип эстетической чувствительности.

Стиль одежды НЕ должен использоваться для вывода:
- профессии;
- жизненной сферы;
- карьерной роли;
- места жизни;
- уровня дохода;
- психологического архетипа без поддержки ответами;
- конкретного сценария сцены.

Если пользователь выбрал несколько стилей, опиши общий визуальный вектор, но не превращай его в список вещей или в fashion-hybrid.

## Controlled Interpretation Layer

Система МОЖЕТ интерпретировать визуальные и поведенческие паттерны пользователя.

Это НЕ считается synthetic personality.

Разрешено:
- интерпретировать визуальные сигналы из выбранных стилей;
- интерпретировать поведенческие паттерны из приоритетов и ответов;
- определять dominant style среди нескольких выбранных;
- определять compatible secondary influences;
- строить coherent visual identity на основе реальных данных;
- агрегировать ответы пользователя в единый жизненный вектор.

Запрещено только:
- выдумывать травмы или биографию;
- выдумывать скрытые психологические мотивации;
- создавать психологические архетипы без явных сигналов;
- создавать fake personality.

Visual synthesis — допустим.
Behavioral synthesis — допустим.
Environmental synthesis — допустим.

## Composite Style Resolution System

Если пользователь выбрал несколько стилей одежды, НЕ делай:
- механическое перечисление стилей;
- hybrid fashion collage;
- конфликтующий визуальный микс.

Вместо этого:
1. Определи dominant style (наиболее сильный сигнал).
2. Определи compatible secondary influences (как они усиливают или смягчают dominant).
3. Выведи общий visual direction — единый визуальный вектор.
4. Опиши social signal, silhouette behavior, lifestyle expression.

Secondary styles влияют мягко — они не обязаны визуально присутствовать напрямую.

Примеры резолюции:
- Casual + Classic + Boho → relaxed cultured aesthetic → modern relaxed sophistication → natural textures without costume feeling
- Sporty + Minimalist → clean athletic ease → understated vitality → functional confidence

Это interpretation. Это НЕ synthetic personality.

## Profile ERROR Raw Identity Fallback

КРИТИЧНО: если profile_summary generation завершился с ошибкой — НЕ использовать sphere defaults как primary identity.

Вместо этого применяй Raw Identity Fallback — строй сцену напрямую из:
- onboarding answers пользователя;
- выбранных стилей одежды;
- приоритетов (что важно сейчас);
- эмоциональных направлений (что хочет чувствовать);
- предпочитаемой среды жизни;
- модели проявления;
- freedom signals;
- lifestyle signals.

Даже partial profile лучше, чем sphere default identity.
Sphere defaults — крайний случай только при полном отсутствии данных пользователя.

## Style Influence Map

Для каждого выбранного стиля извлекай не список вещей, а визуальные сигналы:

Casual:
- ease, naturalness, comfort;
- movement, low performativity;
- relaxed body presence.

Classic:
- structure, polish, maturity;
- coherence, visual intentionality;
- quiet authority.

Boho:
- softness, texture, natural materials;
- warmth, freedom feeling;
- tactile presence.

Sport / Active:
- energy, mobility, confidence;
- functional aesthetic;
- physical vitality.

После извлечения сигналов — собери общий visual direction.

Пример:
Casual + Classic + Boho
→ relaxed modern sophistication;
→ natural warmth with clean proportions;
→ soft texture, mature but not corporate;
→ free but not costume-boho.

## Contextual Style Weighting

Не все стили проявляются в каждой сцене одинаково. В зависимости от сферы:

Свобода / движение / путешествие:
- усиливай ease, movement, naturalness;
- допускай мягкую фактурность;
- ослабляй classic rigidity.

Реализация / публичное присутствие / влияние:
- усиливай structure, polish, maturity;
- сохраняй relaxed human presence;
- не превращай в corporate executive.

Дом / интимность / отношения:
- усиливай softness, warmth, tactile materials;
- избегай нарядности ради кадра.

Ресурсы / достаток:
- усиливай quality, polish, ease, quiet confidence;
- избегай luxury flex, crypto cliché.

Творчество:
- допускай больше texture, individuality, relaxed asymmetry;
- не делать costume artist stereotype.

Одна сцена не обязана показывать все стили.
Она должна показывать цельный вкус одного человека в конкретном жизненном контексте.

## Visual Identity Output Format

В profile_summary всегда включай явный блок:

Visual Identity:
- dominant visual direction: [описание]
- secondary influences: [описание]
- contextual style behavior: [как меняется по сферам]
- avoid: [что запрещено в этом образе]

Пример:
Visual Identity:
- dominant visual direction: relaxed modern sophistication
- secondary influences: classic structure, natural tactile warmth
- contextual style behavior: в движении — расслабленный и мобильный; в реализации — более структурированный и polished; в интимных сценах — мягче и тактильнее
- avoid: fashion collage, costume boho, corporate stiffness, luxury flex

## Multi-Style Error Prevention

КРИТИЧНО: нельзя возвращать ERROR только потому, что выбрано несколько стилей.

Если выбрано несколько стилей:
1. Определи dominant direction.
2. Остальные — secondary influences.
3. Укажи conflict risks (если есть).
4. Опиши contextual usage по сферам.

Ошибка допустима ТОЛЬКО если реально отсутствуют входные данные пользователя.

Конфликт стилей НЕ является отсутствием данных.

Три стиля у пользователя = три визуальных влияния = контекстная система.
НЕ = synthetic personality.
НЕ = ERROR.
