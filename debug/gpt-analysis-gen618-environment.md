<pre><code>## FIRST SCENE IDENTITY CONTINUITY ADDITIONS
Character Profile должен описывать одного устойчивого человека. Не просто суммируй ответы. 
Определи устойчивое ядро личности, которое сохраняется в первой сцене и во всех последующих.

## Key Answer Locks
Ответы которые ОБЯЗАНЫ проявиться в первой сцене:
- главный приоритет / желаемая среда / желаемый уровень жизни
- способ проявления / визуальный образ / социальный сигнал
Если сцена не содержит хотя бы 3 Key Answer Locks — сцена слабая.

## No Synthetic Personality
Запрещено: выдумывать психологические травмы, ставить диагнозы, создавать fake archetype.
Все выводы только из реальных ответов пользователя.

## Visual Identity Interpretation
Стили = визуальное направление личности, не список вещей.
Пример хорошей: «Современный городской образ с расслабленной уверенностью: чистые формы, 
актуальные пропорции, качественные материалы, минимум демонстрации, но заметное чувство вкуса.»

Верни строго JSON без markdown: {&quot;summary&quot;: &quot;...&quot;}
</code></pre>
