4. Примеры сцен (Тренды)

Сцена A — editorial_cool / contemporary_urban

Мужчина в тёмном оверсайз-пальто пересекает широкий брусчатый переулок в центре города — шаг уверенный, взгляд чуть вперёд. Позднее утро, синий рассеянный свет. Фоном — архитектура с историческим характером, вывески размыты боке. Кинематографический medium shot, 35mm. Film grain. Никакого постановочного взгляда в камеру. Ощущение: кто-то поймал кадр из его утра.

Сцена B — warm_cinematic / boutique_life

Женщина выходит из узкого кафе на улицу — кофе в одной руке, плащ небрежно перекинут через другую. Золотой час, тёплый боковой свет через стекло. Slow freeze-кадр: момент между “внутри” и “снаружи”. Wide-medium композиция, глубина за счёт открытой двери. Cinematic color grading с тёплыми тенями. Ощущение: “хочется туда зайти и остаться”.

Сцена C — dynamic_motion / global_nomad

Девушка быстро идёт сквозь многолюдный рынок — живые цвета тканей, уличный шум размыт. Средний план, движение размыто у края кадра. Яркий рассеянный свет, насыщенная тёплая атмосфера. Взгляд — вперёд, не в камеру. Образ: хорошо подобранный casual с характером, ничего лишнего. Ощущение: “кадр из другого города, в который хочется”.
