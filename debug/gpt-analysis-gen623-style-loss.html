6. ДИАГНОСТИКА — ПОЧЕМУ ПОТЕРЯЛСЯ СТИЛЬ

Проблема 1: Сцена не передаётся в deepening-промпт

FAL получает на вход: - Изображение из gen #620 (img2img) - Текст: “другую куртку” + realism rules + style block

Текст НЕ содержит оригинальное описание сцены (аэропорт, локация, свет, поза, ракурс). FAL работает с img2img, но текстовый промпт имеет вес. Если текст не якорит сцену — FAL интерпретирует свободно.

Проблема 2: Нет инструкции “сохрани остальное”

В deepening-промпте нет: - “Сохрани сцену без изменений, кроме куртки” - “Изменить только: куртку” - “НЕ менять: позу, ракурс, локацию, общий образ”

FAL не знает, что всё кроме куртки должно остаться. При img2img + слабом якоре = дрейф.

Проблема 3: Запрос “какую-нибудь” — слишком размытый

“Другую куртку какую-нибудь” не даёт FAL конкретику: - Какой тип? (кожаная, льняная, деним, бомбер?) - Какой цвет? - Вписывается ли в стиль?

При размытой инструкции + img2img FAL может: - Взять куртку из style block (технический нейлон — уже есть в оригинале) - Интерпретировать “другая” как стилистически другая → смена всего образа

Проблема 4: style block конфликтует с запросом

В Base Wardrobe написано “техническая куртка”. Пользователь говорит “другую куртку”. Но в deepening-промпте нет явного OVERRIDE стиля для куртки — и FAL не знает, что именно изменить в рамках заданного стиля.
