7. ДИАГНОСТИКА — ПОЧЕМУ ПОТЕРЯЛСЯ СТИЛЬ В #624

Главная проблема: «wish-режим» НЕ передаёт сцену в FAL

В админке есть два механизма углубления: 1. LLM-режим (#623): LLM пересобирает сцену с учётом контекста → конкретный новый сцена-prompt 2. Wish-режим (#624): Текст пользователя напрямую идёт в FAL → ТОЛЬКО wish + realism + style

Когда пользователь нажимает «углубить с комментарием», система отправляет в FAL:

[user wish] + [generic realism rules] + [generic style block]

Что отсутствует: - Описание сцены (терминал, идёт к гейту, медиум-шот) - Описание уже одетых вещей (свитшот+нейлон-куртка+трикотаж) - Конкретика новой куртки (тип, цвет, материал) - Anchor «всё остальное без изменений»

Конфликт wish ↔ style block

В Base Wardrobe прописано: «техническая куртка». Пользователь говорит «другую». FAL получает противоречие — нет арбитража. FAL произвольно решает: - Взять «техническую куртку» из style block → не изменить ничего - Взять «другую» буквально → подставить произвольную не-техническую куртку - Или поменять весь образ под «другую» интерпретацию

Img2img при размытом промпте

FAL получает изображение из #623 + размытый текст без сцены. При высокой strength img2img — модель меняет больше, чем нужно. При низкой — игнорирует wish.
